# Claude Code Weekly — August 11–17, 2026

Six versions shipped (v2.1.228–v2.1.233), one major behavioral default changed, and Boris Cherny went viral telling everyone to delete their CLAUDE.md. Here's what actually mattered.

---

## 🚀 What Actually Mattered

### 1. Auto Mode Is Now the Default (Aug 14)
**What it does:** New Claude Code sessions on **Pro, Max, and Team** plans now start in auto mode. A background safety classifier evaluates every tool call and only escalates risky, destructive, or out-of-scope operations. Routine file edits, dependency installs, read-only HTTP, and branch pushes run without asking.

**Why it matters:** This is the biggest workflow change of the week. Anthropic cited internal data: the classifier caught **89% of dangerous commands** vs. **14% for humans** doing manual approval in a 1,053-person study. If you were already using auto mode, nothing changes. If you weren't, your sessions now feel dramatically more autonomous. Enterprise/API deployments remain opt-in.

**What to know:** Users who had pinned a personal or org-managed default were not silently overridden. You can revert via `/config`. The classifier tokens are no longer charged separately for eligible users.

**Verification:** ✅ Official — announced by [@ClaudeDevs](https://x.com/ClaudeDevs/status/2088332927189049738), confirmed across [9to5Mac](https://9to5mac.com/2026/08/14/psa-claude-code-enabling-auto-mode-as-default-next-week-anthropic-says/), [canvascode.app](https://canvascode.app/en/news/claude-code-auto-mode-default-what-changes)

### 2. Forked Subagents Now Default (v2.1.232, Aug 13)
**What it does:** `subagent_type: "fork"` is the new default. Forked subagents inherit the **full conversation context and prompt cache** instead of starting cold.

**Why it matters:** Subagents that previously lost all context now retain it automatically. This makes multi-agent workflows — where you spawn exploratory or parallel tasks — significantly more useful without manual context passing. Background execution also became the default for non-teammate agent spawns.

**Verification:** ✅ Official — [changelog](https://x.com/ClaudeCodeLog/status/2088048611565220015), [agentriot.com](https://agentriot.com/news/ai-agents/claude-code-2-1-232-fork-default)

---

### 3. Cross-Session @-Mentions (v2.1.232, Aug 13)
**What it does:** Type `@` in a prompt to mention another live Claude Code session by name. Claude uses `SendMessage` to deliver a plain-text note to the target session. New `/hold` and `/refuse` commands let you control inbound messages. Sessions now auto-deduplicate names to avoid collisions.

**Why it matters:** Builds on the cross-session messaging introduced in v2.1.224 (Aug 7) and makes multi-session coordination feel native. One session can hand off findings, warn about breaking changes, or request help from another — without you copy-pasting between terminals.

**Verification:** ✅ Official — [changelog](https://www.claudeupdates.dev/version/2.1.232), [community guide](https://thepromptshelf.dev/blog/claude-code-cross-session-messaging-guide-2026/)

---

### 4. Synced Skills Security Hardening (v2.1.228, Aug 11)
**What it does:** Claude.ai-synced skills can no longer shadow local commands or MCP prompts, shell execution (`!`) is blocked in synced skills, `@` file expansion is blocked, and metadata is sanitized. Local commands now always take precedence.

**Why it matters:** This closes a real attack surface. A malicious synced skill could previously impersonate a local command or MCP tool. If you rely on synced skills from shared workspaces, this is a meaningful security improvement. **Breaking change** if you had synced skills that intentionally overrode local commands.

**Verification:** ✅ Official — [changelog](https://x.com/ClaudeCodeLog/status/2087274049709707404), [onlylabs.fyi](https://www.onlylabs.fyi/signals/7e76857c-f45c-4dd6-b760-e42d1b82411e)

### 5. Sonnet 5 Pricing Made Permanent at $2/$10 (Aug 11)
**What it does:** Anthropic canceled the planned September 1 price increase. Sonnet 5 stays at **$2/M input, $10/M output** (batch: $1/$5). The previously announced $3/$15 standard rate will not happen.

**Why it matters:** For Claude Code users on API plans, this locks in significantly cheaper costs for the model most people use day-to-day. One caveat noted by the community: Sonnet 5's tokenizer produces ~30% more tokens for equivalent text vs. earlier versions, so real-world cost isn't a pure apples-to-apples comparison.

**Verification:** ✅ Official — [@claudeai announcement](https://x.com/claudeai/status/2086891169217122586), confirmed across multiple sources

### 6. Todo/Task Tools Disabled on Newer Models (v2.1.233, Aug 14)
**What it does:** `TaskCreate`, `TaskGet`, `TaskUpdate`, `TaskList`, and `TodoWrite` are **disabled by default** on Opus 4.8, Sonnet 5, Fable 5, and Mythos 5.

**Why it matters:** If your workflows or skills depend on these tools, they'll silently stop working after updating. Workaround: set `CLAUDE_CODE_ENABLE_TODO_TOOLS=1`. This is a **breaking change** that's easy to miss.

**Verification:** ✅ Official — [DevelopersIO analysis](https://dev.classmethod.jp/en/articles/20260815-cc-updates-v2-1-233/)

## 🔧 Useful Tips & Tricks

### Boris Cherny: "Delete Your CLAUDE.md Every 6 Months"
From a 36-minute talk that went viral this week, the Claude Code lead's advice: **periodically wipe your CLAUDE.md, skills, and hooks, then observe what the model does without them.** The newer models may already handle things your old instructions were compensating for. Treat accumulated context like technical debt.

**Practical approach** (via community adaptation): duplicate your repo, strip the context layer in the copy, test with real tasks, add back only what measurably improves outcomes.

**Source:** [Boris Cherny on X](https://x.com/bcherny/status/2088014489438621990), [clauday.com](https://clauday.com/article/0fd191f5-93b7-4424-979d-5a95a4c87d76) | **Status:** community-reported (attributed to talk, not formal Anthropic policy)

---

### Boris Cherny's "Claude Maintains Apps" Experiment
Boris shared an experiment where Claude runs **daily automated maintenance routines** across Anthropic's own apps (iOS, Android, Desktop, web, CLI, Agent SDK) via a Slack channel called `proj-claude-maintains-apps`. Routines include:
- **Crash fuzzer** — opens app in simulator, taps around to find crashes, root-causes and fixes them
- **Dup unifier** — scans for similar-yet-divergent abstractions
- **Dead-code removal** and **abstraction cleanup**

Result: **388 PRs opened, 180 merged** after review (~46% merge rate).

**Source:** [@bcherny on X](https://x.com/bcherny/status/2088014489438621990) | **Status:** ✅ First-party (Anthropic engineer sharing internal experiment)

### Boris's 4 Ingredients for Agent Tasks
Give agents: **(1)** a high-level task, **(2)** clear guardrails, **(3)** exit criteria, **(4)** room to choose the route. Don't micromanage steps.

**Source:** [Summary thread](https://x.com/nateherk/article/2087567741901287573) | **Status:** community-reported

### Run `/doctor` for Context Hygiene

## 🧭 Bottom Line

**Most important update:** **Auto mode as default.** This fundamentally changes the feel of Claude Code for anyone who hadn't already opted in. The classifier-based safety model replaces manual approval for routine actions, and Anthropic's data suggests it's meaningfully better at catching dangerous commands than humans are.

**Most useful workflow improvement:** **Forked subagents inheriting context by default.** This was the single biggest friction point in multi-agent workflows — subagents starting cold. Now they don't.

**Most important model-related change:** **Sonnet 5 pricing locked at $2/$10 permanently.** No September price hike. For API-based Claude Code users, this removes budget uncertainty. Also note: **Todo/task tools are disabled on newer models** — check if your workflows depend on them.

**Overhyped / low-signal:** The synced skills security changes are important but got outsized coverage relative to how many people actually use synced skills from shared workspaces. The outage was brief and resolved quickly.

**What developers should try now:**
1. **If you haven't used auto mode:** it's now your default — try it for a day before reverting. The classifier is better than you think.
2. **Audit your CLAUDE.md:** take Boris's advice seriously. Strip it down, test, and see what the model handles on its own with Sonnet 5 / Opus 5.
3. **Try cross-session `@`-mentions:** if you run parallel sessions, this is a genuine productivity unlock — one session can hand context to another without you being the relay.
4. **Set `CLAUDE_CODE_ENABLE_TODO_TOOLS=1`** if your workflows broke after updating to v2.1.233.
5. **Plan for Aug 19:** the usage limit drop is real. Budget your heavy Claude Code work accordingly this week.
