# Claude Code news: Sep 22–28, 2026

## 🚀 What Actually Mattered

### 1. Claude Opus 5.5 is out and is now Claude Code's default Opus model (v2.1.280, Sep 22)
- **What it does:** Anthropic says it performs at roughly Fable 5.1 level on most work.
  - Price: $4/$20 per million input/output tokens, down 20% from Opus 5's $5/$25.
  - Cached reads cost $0.20 per million tokens, down 60%.
  - It writes output more than 30% faster than Opus 5.
  - It has a 1M-token context window and can return up to 128K tokens per response.
  - Thinking is always on and can't be turned off. The default effort level is now **medium** (Opus 5 defaulted to high).
  - Anthropic reports 66.4% on Terminal-Bench 4.0, versus 52.3% for Opus 5 and 55.8% for Fable 5.1.
- **Why it matters:**
  - Anthropic's Claude Code post (Sep 24) says Claude now works 3.3x longer per prompt than six months ago, and each request carries 2.6x more context. That makes cached reads most of the bill, so the 60% cut on them is the biggest saving. Long, context-heavy sessions save the most.
  - Anthropic's headline "40% cheaper" compares Opus 5.5 at medium effort with Opus 5 at high. If you pin high or xhigh effort, you won't see that number. Opus 5.5 also thinks more per turn than Opus 5 at the same effort name.
- **Watch out:** an effort level you saved before `/effort` became per-model doesn't carry over to Opus 5.5. It starts at its default.
- **Verification:** official (changelog, [model docs](https://platform.claude.com/docs/en/models/opus-5-5/overview), [blog post](https://claude.com/blog/claude-opus-5-5-built-for-coding-sessions-that-use-more-context)). Benchmarks are Anthropic's own.

### 2. Pro and Team Standard plans now default to Opus instead of Sonnet (v2.1.280)
- **What it does:** If you've never picked a model, Claude Code on the $20 Pro plan now starts on Opus 5.5 instead of Sonnet 5. This matches Max, Team Premium and Enterprise.
- **Why it matters:** Lower-tier users get a much stronger model by default, but Opus uses more of your limits per task. `/model` still switches it.
- **Verification:** official ([model-config docs](https://code.claude.com/docs/en/model-config)).

### 3. Higher usage limits and a reset you can save for later (Sep 22)
- **What it does:**
  - Five-hour limits are up about 20% on Pro, Max, Team and seat-based Enterprise.
  - Anthropic says Opus 5.5's lower price makes those limits go about 25% further.
  - Subscribers also get a one-time limit reset they can use whenever they choose. You trigger it from Settings > Usage on the web or in Claude Desktop, not from the terminal. The reset applies to Claude Code too.
- **Verification:** official ([@claudeai](https://x.com/claudeai/status/2102435525399331254), [Help Center](https://support.claude.com/en/articles/17007452-what-is-a-limit-reset)).

### 4. Claude Code now finishes up cleanly when you hit the 5-hour limit (Sep 25)
- **What it does:** Instead of stopping mid-edit, Claude Code gets a small, fixed allowance to reach a sensible stopping point. In the demo it runs the tests and lists what's still left to do.
  - Pro plans get this once a week. Max and Team Premium get it every time they hit the 5-hour limit.
  - The allowance comes out of your weekly limit. It isn't extra usage.
- **Why it matters:** It fixes a long-standing complaint about sessions ending with half-finished edits. It pairs well with the existing "Continue automatically at usage limit" setting in `/config`.
- **Verification:** official, from [@ClaudeDevs](https://x.com/ClaudeDevs/status/2103561342057943314), rolling out gradually. It wasn't in the changelog when I checked.

### 5. Plugin submission portal and MCP 2.0 support (Sep 25)
- **What it does:**
  - Developers on paid plans can submit plugins through a portal at claude.ai/directory/manage. Submissions are checked and safety-scanned automatically, you can track review status, and you get install and search analytics once a plugin is live.
  - In Claude Code, a plugin can bundle MCP servers, skills, LSPs (language servers), commands, hooks and agents.
  - Claude now supports MCP 2.0, the latest spec, which has a stateless core. It also supports two extensions: MCP Apps (interactive UI inside chat) and Enterprise Managed Auth (OAuth with no setup for enterprise users).
- **Why it matters:** Plugins are now the official way to build extensions for Claude. Anthropic says MCP usage across its products is up 110x this year. A single plugin discovery experience across Claude and Claude Code is coming "in the coming weeks."
- **Verification:** official ([blog](https://claude.com/blog/build-plugins-for-claude), [submission docs](https://claude.com/docs/plugins/submit)).

### 6. `/doctor prompt-audit` and admin model controls (v2.1.283, Sep 25)
- **What it does:**
  - `/doctor prompt-audit` (also `/checkup prompt-audit`) checks your CLAUDE.md, skills, agents and commands for prompting habits written for older models. Stale paths, stale commands and conflicting instruction files appear first in the report.
  - Two new admin settings: `availableModelsMatch: "exact"` pins allowed models to exact versions, and `deniedModels` blocks specific models.
- **Other fixes in this window worth knowing:**
  - v2.1.281: `rm -rf "$(pwd)"`-style commands no longer run without asking in auto mode.
  - v2.1.281: resumed sessions no longer lose earlier reasoning or prompt cache.
  - v2.1.280: writes through a symlink are now judged by where they actually land.
- **Verification:** official ([changelog](https://code.claude.com/docs/en/changelog)).

## 🔧 Useful Tips & Tricks

- **Re-check your effort setting.** Start at `/effort medium`, go to `high` when medium stalls, and use `low` for renames and other mechanical work.
  - Community consensus is split between medium and high. I didn't find anyone recommending max.
  - Anthropic says that with an API key or a subscription, changing effort mid-task keeps your cache. On cloud providers or gateways, change it at a natural break.
  - *Official ([claude.com blog](https://claude.com/blog/what-a-task-costs-on-opus-5-5)) plus community ([note.com](https://note.com/masa_wunder/n/n110c9e426b01?hl=en)).*
- **Clean up prompts written for older models.** `/claude-api prompt-audit` does this for prompts in your code, tool descriptions and skills, and proposes changes as diffs. The new `/doctor prompt-audit` covers your Claude Code config. One user said removing 4 old skills made the model less hesitant to use tools.
  - Treat each deletion as a guess and test before and after.
  - *Official command; results are community-reported ([Zenn](https://zenn.dev/irosona/articles/claude-api-prompt-audit-devlog-pipeline?locale=en), [X](https://x.com/Hyde_ai3/status/2103231349389967812)).*
- **Save the free reset for a long agent run** instead of using it on day one. *Community advice.*
- **AGENTS.md now works as a fallback.** Since v2.1.277 (Sep 18), projects without a CLAUDE.md read AGENTS.md instead. Some Claude Code vs Codex comparisons still say it's unsupported, which is out of date. *Official.*
- **`"attribution": false`** in settings.json hides Claude's attribution in commits and PRs (v2.1.281). **`maxProseWidth`** limits how wide Claude's prose gets in wide terminals (v2.1.282). *Official.*
- **Prompt cache complaints:** one report says the 1-hour cache expires every 11–12 minutes, and GitHub issue #95222 says cache re-writes eat into usage. Check `/cost` for cache-miss causes. *Community-reported, unconfirmed.*

## 🧭 Bottom Line

- **Most important update:** Opus 5.5 becoming the default, including on Pro and Team Standard. You get near-Fable quality for less, and the 60% cheaper cache reads fit how people now use Claude Code.
- **Most useful workflow improvement:** the graceful wrap-up at the 5-hour limit. It's small, but it ends broken half-edits.
- **Most important model-related change:** the default effort dropped to medium and thinking can't be turned off. If you carried over high or xhigh from Opus 5, you'll use more tokens than you need to.
- **Overhyped or low-signal:**
  - The "40% cheaper" headline, since it compares medium effort against high.
  - Benchmark wins, since most are Anthropic's own numbers.
  - GPT-6 Sol launched the same day at half the per-token price. Independent comparisons put it behind Opus 5.5 on agentic coding but ahead on cost per task.
- **What developers should try now:**
  1. Run `claude update` to get v2.1.280 or later.
  2. Run `/effort status`, then try the same hard task at medium and at high.
  3. Run `/doctor prompt-audit` on your CLAUDE.md and skills.
  4. If you maintain MCP servers or skills, package them as a plugin and submit them through the new portal.
